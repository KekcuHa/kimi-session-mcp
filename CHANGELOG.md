# Журнал изменений

## [0.0.3] — 2026-11-14
- Публикация на GitHub: лицензия MIT, метаданные package.json (author, repository, keywords), снят флаг `private`.
- README стал двуязычным (английский основной, русский ниже); пути установки обобщены под `git clone`.
- Локальный `.kimi-code/mcp.json` с машинно-специфичными путями исключён из репозитория (.gitignore).

## [0.0.2] — 2026-11-14
- README: раздел «Управление сеансами через REST» — создание (`POST /api/v1/sessions`), удаление (`POST …/sessions/{id}:delete`; обычного `DELETE` нет), архив (`:archive`, пакетные `/api/v2/sessions:archive|:restore`), `:reload`, `:takeover`.
- README: в «Ограничения» — MCP-конфиг Kimi подхватывается только новыми сеансами; получатель без MCP-инструментов отвечает только в свой транскрипт, ответ забирать через `GetMessages`.

## [0.0.1] — 2026-11-05
- Добавлен MCP-сервер для обнаружения сеансов Kimi Code и обмена текстовыми сообщениями через локальный REST API.
- Добавлены доставка в активный ход через `prompts:steer` и чтение ответов через `GetMessages`.
- Проведена сквозная проверка обмена между двумя реальными сеансами Kimi Code 2.4.1.
