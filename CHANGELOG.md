# Журнал изменений

## [0.0.2] — 2026-11-14
- Проведена повторная сквозная проверка MCP и сравнение с AgentMBX.
- Основным механизмом обмена выбран AgentMBX; автоматическая загрузка `kimi-sessions` в проекте отключена.
- Код сохранён как резервный вариант с возможностью ручного подключения.

## [0.0.1] — 2026-11-05
- Добавлен MCP-сервер для обнаружения сеансов Kimi Code и обмена текстовыми сообщениями через локальный REST API.
- Добавлены доставка в активный ход через `prompts:steer` и чтение ответов через `GetMessages`.
- Проведена сквозная проверка обмена между двумя реальными сеансами Kimi Code 2.4.1.
